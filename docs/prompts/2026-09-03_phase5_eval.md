# Task brief: Phase 5 — Evaluation harness

## Project context

`src/docvalidator` — core layers + API are DONE. Fixtures live in `fixtures/invoices/*.txt`
with sibling `*.expected.json` files containing expected extracted fields (key → value or null)
and expected verdict status. Read the fixtures and the extraction/rules code first.

## Deliverable — `eval/` package (runnable as `uv run python -m eval.run`)

`eval/run.py`:
- Loads every `fixtures/invoices/*.txt` + its `.expected.json`
- Runs the offline extractor + rules engine (default config from expected.json if present,
  else the config example from the assessment: max_age_days=90, allowed_currencies=[EUR,GBP])
- Per FIELD metrics across fixtures: exact-match rate (predicted == expected, treating None==None
  as match but reported separately as "missing-predicted"), and per-field precision/recall over
  non-null expectations
- VERDICT metric: agreement rate between produced status and expected status
- Prints a clean table per field + overall verdict agreement, then a FAILURES section listing
  every mismatch: fixture name, field, expected vs got (+ evidence snippet), and every verdict
  disagreement with the rule results that caused it
- Exit code 0 always (it's a report, not a test) — but print a final one-line summary:
  `OVERALL: field_accuracy=X.XX verdict_agreement=X.XX (N fixtures)`
- `--json out.json` flag writes the full metrics dict for CI/regression use

Metrics implementation in `eval/metrics.py` (pure functions, unit-testable).

## Tests (`tests/unit/test_metrics.py`)

Cover: exact match counting, None handling, precision/recall math on a tiny hand-built case,
verdict agreement. ~10 asserts.

## Quality gates

1. `uv run ruff check .` clean; 2. `uv run pytest` green; 3. `uv run python -m eval.run` runs
end-to-end and prints the table — paste its full output in your report.

Do NOT touch src/ or api/ code. If a fixture expectation is genuinely wrong relative to the
extractor's documented confidence semantics, report it — do not silently "fix" fixtures to pass.
